# Techfest 3D Interactive Core
A 100-point WebGL interactive experience built for the IIT Bombay Techfest College Ambassador program.

## 🚀 Live Deployment
**[View the Live 3D Experience Here](https://techfest-3d-core.vercel.app)** 

## ⚙️ Technical Architecture
* **Framework:** Next.js (App Router)
* **3D Engine:** Three.js & React Three Fiber
* **Controls:** Drei OrbitControls & Environment Mapping
* **Interactivity:** Dynamic state-driven object rendering (Hover/Click mutations)
